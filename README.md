# NestJS Estudos

Este repositório foi criado apenas para fins de estudo e prática com **NestJS**.

O objetivo é registrar meu aprendizado, testes, exercícios e pequenos projetos desenvolvidos durante meus estudos sobre desenvolvimento backend com NestJS.

## Objetivo

- Praticar conceitos de NestJS
- Estudar estrutura de projetos backend
- Criar APIs REST
- Entender controllers, services e modules
- Praticar integração com banco de dados
- Registrar minha evolução nos estudos

## Aviso

Este repositório não representa um projeto finalizado ou pronto para produção.  
Ele é destinado apenas para aprendizado e experimentação.
